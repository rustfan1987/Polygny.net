# Polygny

Polygny is a SvelteKit, TypeScript, Tailwind CSS, and Firebase application.

## Development

Install dependencies and start the local server:

```sh
npm install
npm run dev
```

Run project checks and create a production build:

```sh
npm run check
npm run build
```

Copy `.env.example` to `.env` and supply the Firebase Web App configuration before running locally. Firebase integration details live in `src/lib/firebase/README.md`.
